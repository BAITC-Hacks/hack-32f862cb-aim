## Перезапуск и восстановление

1. Проверена инициализация образа PostgreSQL с пустым volume: созданы `optistock` и `optistock_test`, роль приложения `rolsuper = false`.
2. Перезапущены PostgreSQL, API и worker. Readiness восстановилась; сводки набора и плана совпали, оба утверждённых CSV совпали побайтно с результатами до перезапуска.
3. Выполнен `pg_dump -Fc`, создан архив исходных файлов из volume. Dump восстановлен через `pg_restore --exit-on-error` в отдельную временную БД: 3909 товаров, 3909 рекомендаций, 2 заказа. Временная проверочная БД после проверки удалена.

В описанном выше backend-запуске API был доступен на `http://localhost:8000`; доступ к данным требует персонального ключа. Отправка поставщикам, интеграция 1С и HA-кластер не входят в проверенную реализацию.

## React frontend — отдельная проверка

Проверено 23 сентября 2026 года на Windows, Node.js 24.21.0, Chromium через Playwright. Результаты этого этапа не означают повторный запуск описанных выше backend-проверок.

- `npm run build`: TypeScript strict и production-сборка Vite проходят. Страницы и графики разделены на отдельные загружаемые модули.
- `npm run lint`: без ошибок и предупреждений.
- `npm test`: **14 passed**. Проверены глобальный поиск и Enter/Escape, фильтрация, пагинация, выбор строк и CSV, изменение/утверждение/отмена заказа, ревизии, сохранение демо, расчёт сценария, отсутствие повторных черновиков и все страницы.
- Проверки API-контракта на контролируемых HTTP-ответах: Bearer, Idempotency-Key и его повторное использование после 503, серверные роли, неизвестный остаток, объяснение рекомендации, импорт с polling, каталог больше 200 записей, повторное подключение и ошибки ключей.
- Проверена ширина страниц на 390 и 1024 px, визуально просмотрен dashboard на 1536 и 390 px. Тесты сохраняют снимки в `frontend/test-results/` (не в Git).
- `npm run format:check`: форматирование Prettier.

Docker CLI в этой Windows-среде отсутствует: frontend Nginx-образ, Compose и полный браузерный сценарий с настоящими PostgreSQL/FastAPI/worker здесь не запускались. API-интеграция проверена по существующим серверным маршрутам и браузерным тестам с ответами по их контракту. Backend-код и исходные XLSX не изменялись.

Локальный интерфейс: `http://localhost:5173`. Запуск, подключение ключа и ограничения деморежима: [frontend/README.md](frontend/README.md).
